# Antigravity Quota Widget ⚡

> Native Android App & Home Screen Widget for Antigravity (Google DeepMind) AI Quota & Limits.

Track your live AI model quotas and reset countdowns for **Gemini Pro/Flash**, **Claude**, and **GPT** directly from your Android phone and home screen.

## ✨ Features

- ⚡ **Antigravity Quota Tracking:** Real-time monitoring of model buckets, remaining quotas, and reset times.
- 📱 **Home Screen Widget:** Glance-powered compact widget showing Gemini and Claude/GPT status without opening the app.
- 🌐 **Browser Google Login:** One-tap Google sign-in via Custom Tabs or manual session JSON / Access Token input.
- 🔒 **Secure KeyStore Storage:** Android KeyStore AES-256 GCM hardware-backed encrypted storage for session credentials.
- 🎨 **Modern Dark UI:** Clean, minimalist UI matching dark developer aesthetics.

## 🚀 Download APK

Download the latest prebuilt debug APK from [GitHub Releases](https://github.com/ireza7/CodexBar/releases).

## 🛠️ Build from Source

```bash
cd android
./gradlew assembleDebug
```

Output APK will be located at:
`android/app/build/outputs/apk/debug/app-debug.apk`
